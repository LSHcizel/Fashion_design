# 改写前后得分对比 · 论文图说明

供后续 **GPT Images** 绘制论文用对比图（宏观柱图 + 子维度横条图）。  
数据来自 400 组：每组 **组内最高改写** vs **同组原文**；分层 **全部 / 逆解析 / 生成图**。  
视觉语言对齐参考图：浅底、蓝正向横条、灰负向横条、0 基线、虚线标整体均值、条端数值标签。

---

## 0. 一句话口径

> **每组只取改写总分 \(S_{fp}\) 最高的一条，减去该组原文分，再对组取平均。**  
> 得分门 \(\tau_s=0.8\)，惩罚门 \(\tau_p=0.25\)（惩罚不扣减 \(S_{fp}\)，只进门限）。

\[
S_{fp}=0.2\cdot C + 0.8\cdot Q_w
\]

- **Coverage 子维（5）**：GarmentCore · MaterialColor · ConstructionDetail · StylingSet · Composition  
- **Quality 子维（7）**：DesignMerit · ConcisenessAndDensity · InformationDensity · GenerationReadiness · BindingAccuracy · LanguageClarity · StructuralClarity  

分层：`sample_kind=inverse` → 逆解析 200；其余 → 生成图 200。

### 勿画进图

- 训练 / GRPO / RM / 采样脚本细节  
- 惩罚五项细项（本套图只报得分轴）  
- PPT 仪表盘、UI 控件、3D 效果

## 3. 版式规范（两图共用）

### 3.1 宏观双面板（Fig-M-*）

```
┌─────────────────────────────────────────────────────────────┐
│  Title（英文）                                              │
│  ┌──────────────────────┐  ┌────────────────────────────┐ │
│  │ Scores: Orig vs Best │  │ Gate pass rate (%)         │ │
│  │ clustered bars       │  │ clustered bars             │ │
│  │ Gray=Original        │  │ Gray=Original              │ │
│  │ Red =Best rewrite    │  │ Red =Best rewrite          │ │
│  │ cats: S_fp, Q, C     │  │ cats: Score, Penalty, Both │ │
│  └──────────────────────┘  └────────────────────────────┘ │
│  Caption（一行）                                            │
└─────────────────────────────────────────────────────────────┘
```

- 左轴分数 0–1.0；右轴通过率 0–100  
- 柱顶标精确数值（分数 3 位小数；通过率 1 位小数）  
- 无 3D、无渐变、无数据点装饰  

### 3.2 子维度横条（Fig-D-*）——对齐参考图

```
┌─────────────────────────────────────────────────────────────┐
│  Title（英文）                                              │
│                                                             │
│  Category labels │ ████████████████ +xx.x%   (blue if ≥0) │
│                  │ ████ +yy.y%                              │
│                  │ ▐ 0                                      │
│                  │ ███ -zz.z%              (gray if <0)     │
│                    ↑ solid zero    ↑ dashed mean lift       │
│  Legend: Positive | Negative | Overall mean +m.m%           │
│  Footnote: protocol one-liner + S_fp lift                   │
└─────────────────────────────────────────────────────────────┘
```

**硬规则**

1. **按 Lift 降序**排列（最大提升在最上）  
2. **正向 = Muted blue**（约 `#5B8DB8`）；**负向 = muted gray**（约 `#A8A8A8`）  
3. **实线竖线 @ 0**；**虚线竖线 @ 维度均值**  
4. 每条末端写 `+12.3%` / `-7.0%`（一位小数）  
5. 浅灰竖向网格；白底；无圆角胶囊、无阴影、无图标  
6. Y 轴用 **英文 Category 名**（与 §2.2 表一致）；勿写中文进论文终稿图  
7. X 轴标题：`Improvement after rewrite (percentage points)`  
8. 图注写清：best-in-group rewrite − original, then mean over groups  

### 3.3 配色与字体

| 元素 | 建议 |
|---|---|
| 原文柱 | `#B0B0B0` |
| 最高改写柱 | `#C0392B` 或同系深红 |
| 正向横条 | `#5B8DB8` |
| 负向横条 | `#A8A8A8` |
| 0 线 | `#888888` |
| 均值虚线 | `#222222` |
| 网格 | `#D8D8D8` |
| 字体 | 无衬线学术体（类似 Computer Modern / Helvetica）；英文 only |
