# Corpus Construction · 论文流程图说明

供后续 **GPT Images / GPT Image** 绘制论文用 flowchart。  
视觉语言**严格对齐**参考插图 *Step 1: Data Generation*（紫框标题、圆柱数据集、灰底 API 盒、粗蓝渐变箭头、虚线扇出列表）。

核心主张：语料库由 **两条并行路径** 汇合而成——

1. **Path A — API 逆解析**（Image → Multimodal API → `text_description`）  
2. **Path B — 工作流直接生成**（Theme → Fashion Agents Workflow → `look_XX.txt`）

---

## 0. 一句话主干

> **真实秀场图经多模态 API 逆解析为正样本；主题经多智能体工作流直接生成 look 描述为另一路样本；两路汇合为 Source Corpus。**

## 3. 主图各块文案（英文，便于出图）

### Path A — Reverse Parsing via API Call

| 顺序 | 节点 | 形态 | 文案 |
|------|------|------|------|
| A1 | 输入集 | 圆柱 + 顶部小图示 | `Image Set` |
| A2 | 辅输入 | 粉红描边小盒（在 API 盒下方，细蓝箭头向上） | `Inverse Parse Prompt` |
| A3 | 处理 | 灰底盒 + 彩色 sparkle | `Multimodal API` |
| A4 | 中间产物 | 白底圆角盒 | `text_description` |
| A5 | collect | 细蓝弯箭头 + 橙色旁注 `collect` | 指向圆柱 `Positive Set` |
| A6 | 扇出（可选） | 虚线框列表 | `$desc_1, desc_2, \ldots, desc_N$` |

旁注（小号、灰字，可选）：`image-faithful reverse parse`

### Path B — Direct Generation via Workflow

| 顺序 | 节点 | 形态 | 文案 |
|------|------|------|------|
| B1 | 输入 | 圆柱或圆角输入盒 | `Theme + Design Target` |
| B2 | 处理 | 灰底盒（可无 sparkle，或轻标 agents） | `Fashion Agents Workflow` |
| B3 | 链内缩写（小字） | 一条短链即可 | `Theme → Concept → Elements → Look` |
| B4 | 扇出 | 虚线框列表 | `$look_1, look_2, \ldots, look_N$` |
| B5 | collect | 细蓝弯箭头 + `collect` | 指向圆柱 `Workflow Set` |

旁注（小号）：`multi-agent direct generation`

### Merge — Unified Corpus

| 节点 | 形态 | 文案 |
|------|------|------|
| 汇合箭头 | 两条粗蓝箭头汇入 | 从 `Positive Set` 与 `Workflow Set` |
| 最终库 | 深色圆柱 | `Source Corpus` |
| 副标题（可选） | 圆柱旁小字 | `positive ∩ reverse-parse  +  workflow looks` |

## 4. 视觉规范（对齐参考图）

| 元素 | 规范 |
|------|------|
| 画幅 | 横向 landscape，白底，高分辨率 |
| 外框 | `#9B7BB8` / 淡紫细线，大圆角 |
| 标题 | 紫色，压边框；左右紫点 |
| Path 标签 | 可用小紫/蓝标签条：`Path A: API Inverse Parse` / `Path B: Workflow Direct Gen` |
| API / 处理盒 | 灰填充 `#5A5A5A`–`#6E6E6E`，白字 |
| 数据态盒 | 白底 + 轻阴影，黑粗衬线字 |
| 主箭头 | 粗、半透明蓝渐变 |
| 列表框 | 浅灰虚线圆角；条目用数学下标 |
| 字体 | 标题可衬线；模块名清晰可读；主标注英文 |
| 禁止 | 训练火焰、GRPO/SFT 字样、红虚线 policy loop、K 路改写细节、Evaluator 门限表 |
