# DesignTextEvaluator · 得分项 / 惩罚项 · 论文维度表说明

供后续绘制论文用 **Table（学术表格）**，版式对齐参考图：  
*Table 1: A Multi-dimensional Evaluation Framework for Text-to-Image Generation*  
（五列层级表：Super-Category → Category → Key Point → Example → Criteria）。

**规格真相源**：`plugins/text_description_evaluator/fashion_prompt_optimizer_spec.json`（v0.5.1）  
**双门限口径**：`S_fp ≥ τ_s` 且 `P̄ ≤ τ_p`；惩罚**不扣减** `S_fp` / `R_content`，仅进 `penalty_gate`。

## 0. 与参考表的对应关系

| 参考论文列 | 本项目映射 | 说明 |
|---|---|---|
| Super-Category | 轴 / 惩罚大类 | 得分表：Coverage / Quality；惩罚表：Identity / Wearability / Prompt Efficiency |
| Category | 模块（module） | 如 GarmentCore、DesignMerit、Consistency |
| Key Point | 具体指标 / 惩罚项 | `**英文名** – 一句短释义` |
| Example | 可成像 Prompt 示例 | 统一前缀 `Prompt:`；括号内点明考察点 |
| Criteria | 计分码 | `Cov` / `Q` / `Pen`（见下） |

### Criteria 缩写（画进表注）

| Code | Meaning | Scale |
|---|---|---|
| **Cov** | Coverage hit（覆盖轴） | binary：命中 1 / 未命中 0；仅对适用项取平均 |
| **Q** | Quality score（质量轴） | 五档：0 / 0.25 / 0.5 / 0.75 / 1.0；模块内适用项平均，再按模块权重合成 |
| **Pen** | Local quality penalty（惩罚项） | 五档：0 最好 → 1.0 最差；五项算术平均得 `P̄` |

### 总分与门限（表注可放一行）

\[
S_{fp} = 0.2\cdot C + 0.8\cdot Q_w,\quad
\bar P = \mathrm{mean}(P_i),\quad
\text{pass iff } S_{fp}\ge \tau_s\ \land\ \bar P\le \tau_p
\]

当前默认：`τ_s = 0.8`，`τ_p = 0.25`（见 `fashion_config.yaml` / `optimization_gates`）。

质量模块权重（进 `Q_w`）：DesignMerit 10 · ConcisenessAndDensity 5 · InformationDensity 5 · GenerationReadiness 5 · BindingAccuracy / LanguageClarity / StructuralClarity 各 1。

### 2.2 惩罚项中文名与规格 key

| Key Point | 规格 key | 中文名 | 硬规则摘要（表注可选） |
|---|---|---|---|
| Consistency | `consistency_penalty` | 一致性惩罚 | 主干衣裤鞋（含明示里衬）左右/同件互斥 → 通常 ≥0.75；两类及以上 → 1.0 |
| Coordination | `coordination_penalty` | 协调性惩罚 | 主干气质/场域对撞或另一主题服装仍在 → 通常 ≥0.75 |
| Rationality | `rationality_penalty` | 合理性惩罚 | 违反材质/物理/穿着常识 |
| Non-generative Content | `generation_content_penalty` | 非生成导向内容 | Look 编号/拼贴/平铺/离身货品句 → 通常 ≥0.75 |

### 3.2 视觉规范（对齐参考 Table 1）

复制参考表的视觉语言，**不要**做成仪表盘或卡片墙：

1. **五列**：Super-Category | Category | Key Point | Example | Criteria  
2. **合并单元格**：同一 Super-Category / Category 纵向合并（Markdown 用留空模拟；LaTeX/`booktabs`/PPT 用真合并）  
3. **分隔**：表头粗线；每个 Super-Category 块之间加粗横线；**无竖线**  
4. **斑马纹**：同一 Super-Category 内行交替浅灰 / 白  
5. **Key Point**：`**粗体术语** – 短释义`（用 en-dash `–`）  
6. **Example**：统一 `Prompt: …`；括号补考察点；惩罚表示例可加 `→ high Pen`  
7. **Criteria 列**：居中短码 `Cov` / `Q` / `Pen`  
8. **题注**：表下用一行解释缩写（仿 “TIC = …; SI = …”）  
9. **语言**：论文正文表优先 **英文**；中文汇报可用双语 Key Point 或另附中文速查  
10. **禁止**：把训练/GRPO/RM、改写 K 路、门限优化流程画进维度表；表只承载**评价维度 taxonomy**

## 4. 一页纸摘要（可放论文附录开头）

**得分项**：覆盖轴问「有没有」（Cov，二元），质量轴问「好不好」（Q，五档）；合成 \(S_{fp}=0.2C+0.8Q_w\)。  
**惩罚项**：五项局部缺陷（Pen，0 最好）；\(\bar P\) 只守惩罚门。  
**双门限**：高分且低惩罚才进入 T2I；改写采纳须相对原文 \(S_{fp}\uparrow\) 且 \(\bar P\downarrow\)。
