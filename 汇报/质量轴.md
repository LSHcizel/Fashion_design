**软性规则**（参考逆解析 corpus：`wgsn_batch_image_inverse/20260524T044337Z`）

- 优先识别「沿具体部位路径展开」的工艺/装饰锚点（如 appliqué/trim 沿 neckline、front edges、cuffs、hem、pocket edges），而非仅列品类名
- 异材质碰撞、非常规比例、强识别图案/print、手工感 texture 写清为记忆点
- 结构亮点（boxy/cropped/dropped waist/deep V/asymmetric panels）若具造型主导性，可与工艺并列计为锚点
- 金属扣、pendant、chain 写清位置与视觉作用可作辅助识别点；纯 gold-tone hardware 泛称加分有限
- 高分记忆点应能区分「这一件 look」，而非换色即可套用的组合

**视觉观察锚定**

| 分数 | 标准 |
|------|------|
| 1.0 | 多处具体部位锚定，可见/不可见层次清楚，几乎无氛围/评论句 |
| 0.75 | 主要结构有可见锚定，概念句极少（≤1 处轻量） |
| 0.5 | 观察与概念/氛围句混合；锚定尚可但工艺观察不足 |
| 0.25 | 以主题/氛围/沙龙/漫步等修辞为主；或仅有叠搭/下摆等泛锚定 |
| 0.0 | 纯概念叙事或套路化文本，无法对应可见造型 |

**软性规则**（参考逆解析 corpus）

- 正文按「主干单品 → 内外层次 → 下装/鞋配 → styling 配件」空间递进
- 常见部位锚定：neckline/collar、shoulders、sleeves、waist、hem、center front、cuffs、pockets（至少 3 类）
- 层次用 worn open over / beneath / underneath / partly obscured / visible at 等可见语言（corpus 约 77%）
- 不确定处用 appears / could be / not confirmed 或 uncertainty_notes，优于编造 unseen 细节
- 段末 1 句 overall mood/palette 可接受（约 1/3）；中段大量 mood/essay 仍低分

| 0.0 | 应写工艺处完全缺失或空泛 |

**软性规则**（参考逆解析 corpus）

- 须写清「类型 + 路径/位置 + 视觉作用」三要素
- 偏好具体 craft 词：appliqué、braid trim、fringe、piping、embellishment、woven pattern、panel graphic
- craft 为 look 主 hook 时在前 2/3 展开，而非段末一笔带过
- texture（shaggy、bouclé-like、openwork crochet 等）应连位置与作用一起写

**组合原创性**

| 分数 | 标准 |
|------|------|
| 1.0 | 组合高度具体且难预测，换一件主干单品会改变整体读感 |
| 0.75 | 组合有明确取向，但仍有部分常规元素 |
| 0.5 | 安全奢华组合可预测；或叠搭略增趣但仍属度假公式 |
| 0.25 | 典型 formula 组合，可预测；或主干单品可互换而不改变整体读感 |
| 0.0 | 最常见巡航/工装模板拼接，多条造型间可互换主干 |

**软性规则**（参考逆解析 corpus）

- 常以外穿 + 内搭 + 下装 + 包鞋配四层组合描述完整 look
- 高分组合用 contrast 语言：structured vs sporty、voluminous outer vs flat graphic inner
- layering 逻辑具体时，即使品类偏常规仍可中高分
- 鞋包首饰若写入组合逻辑（echoing embellishments、palette contrast）视为组合一部分
- 按「换一件主干单品是否改读感」区分，而非仅看 luxury formula

| 分数 | 标准 |

**软性规则**（参考逆解析 corpus）

- 正文以可成像设计事实为主（品类/廓形/材质/颜色/pattern/craft 位置/层次/配件位置）
- Styling includes / carries 引导的配件鞋履描述计为设计事实，不算 mood essay
- 段末 1 句 overall mood/palette 可接受；≥2 句或中段反复 mood framing 则降分
- 不写品牌名、不编造 unseen back / hidden closure
- 具体色名 + 作用优于抽象奢华/度假评论

## 上限规则

- 属性绑定模块得分 **低于 0.5** 时，质量轴得分 **最高只能到 0.6**（即使其他模块很高也上不去）

## 得分计算公式

**模块得分**  
- 各指标五档计分（0 / 0.25 / 0.5 / 0.75 / 1.0）  
- 模块分 = 该模块 **适用指标** 的算术平均

**质量加权均分 Q_w**

```
Q_w = Σ(模块权重 × 模块分) / Σ(模块权重)
```

| 模块 | 权重 |
|------|------|
| 设计价值 | 10.0 |
| 可见性优先级 | 5.0 |
| 生成适配 | 5.0 |
| 属性绑定 | 1.0 |
| 语言清晰 | 1.0 |
| 结构清晰 | 1.0 |

**质量有效分 Q**

```
Q = min(Q_w, cap_q)
```

- 默认 cap_q = 1.0  
- 属性绑定模块分 < 0.5 时，cap_q = 0.6

**并入综合分**

```
S_fp 的内容主分部分 = 0.2 × C + 0.8 × Q
```
