# 惩罚分

**计分**：每项 0~1 分五档（0 最好，1 最差）  
**综合惩罚分**：5 项取平均  
**通过条件**：综合惩罚分 **不超过 0.5**  
**作用**：**暂不直接从总分里扣分**，只决定能不能通过惩罚门限

**档位说明**：只能在 **0 / 0.25 / 0.5 / 0.75 / 1.0** 五档中选值

---

## 惩罚项概览

| 惩罚项 | 核心判定 |
|--------|----------|
| 非生成导向内容 | 冗余重复、氛围评论、分析解说、风格符号堆砌 |
| 一致性 | 主干（衣裤鞋/里衬）左右或同件互斥 |
| 协调性 | 主干间造型气质/场域冲突 |
| 合理性 | 违反物理/穿着常识（材质、腿带绑具等） |
| 公式模板 | 巡航度假公式、品牌符号堆叠、可互换造型 |

---

## 非生成导向内容

| 分数 | 标准 |
|------|------|
| 0 | 无显著冗余、概念阐释或评论句；生成导向清晰，可见主体可聚焦 |
| 0.25 | 少量重复或 1–2 处轻量概念/评论表述，不显著稀释成像信息 |
| 0.5 | 同一信息多处重复、明显偏向历史类比/runway 评论；或 **≥3 处**氛围/姿态/沙龙/漫步/仿佛/暗示类句 |
| 0.75 | 在 0.5 基础上，再叠加可互换度假公式、品牌符号堆叠无工艺识别点，或冗长重复铺垫 |
| 1.0 | 大量互异风格符号堆叠，未先交代主干廓形与层次，prompt 难以还原可见造型 |

---

## 一致性

**主干范围**：全部衣裤鞋（外穿、内搭、裤装、鞋履）；明确写出的外套里布、裤装内衬/开衩内衬与壳面一体时同等对待。  
**从宽**：仅配饰（腰带、手套、首饰、包等）轻度左右差异，且主干已统一 → 不因此加罚。

| 分数 | 标准 |
|------|------|
| 0 | 所有主干单品结构/身份统一可读，无左右或同件互斥 |
| 0.25 | 已收束为单一可读主干语法，或仅一笔轻描不对称；或已删去较弱互斥支路 |
| 0.5 | 任一件主干出现左右割裂、互斥品类/材质/结构；或 **≥2 类**主干层级同时左右互斥（如袖+裤+鞋） |
| 0.75 | 多区主干对撞未收束；单件「半件正装半件另一语汇」且无统一语法；壳与里衬两套互斥身份 |
| 1.0 | 多条互斥「主体身份」并列（多袖态+双腿异料+双脚异鞋+手套/裸手等），仅以「解构」一句带过 |

---

## 协调性

**从宽**：违和仅来自小配饰且轻微、主干衣裤鞋已统一语气 → 不因此加罚。

| 分数 | 标准 |
|------|------|
| 0 | 外套、内搭、裤、鞋及里衬/内衬场域统一，层次衔接可读 |
| 0.25 | 整体协调，仅配饰或局部细节轻微气质差异 |
| 0.5 | 同件上装左右互斥场域；内外层语气打架；鞋与套装严重冲突；腿带绑具与裤型结构违和；**上装/裤装已分裂且左右脚鞋履场域仍严重互斥** |
| 0.75 | 多区主干场域对撞；哑光外套与单侧高光金属护臂等同件主干上且无收束 |
| 1.0 | 整体造型场域完全脱节，无法收束为单一可读 look |

---

## 合理性

| 分数 | 标准 |
|------|------|
| 0 | 材质、结构、穿着关系符合现实常识 |
| 0.25 | 极轻微不合理，文本中有可解释的空间 |
| 0.5 | 部分设定勉强成立；腿带/吊带与阔腿或宽松裤管关系交代不清但尚可想象 |
| 0.75 | 明显违反现实材质或物理条件（如不锈钢/水银作衣料主体）；腿带+harness 与裤型在物理上难以同时成立 |
| 1.0 | 严重违背穿着常识，装束关系在现实中无法成立 |

---

## 公式模板

**总领性判断**：不看段落标题或子弹点格式，看整体是否像可互换的公式稿。

| 分数 | 标准 |
|------|------|
| 0~0.25 | 紧凑、基于可见观察的表述，无下列特征 |
| 0.25~0.5 | 明显命中 **1 项**：① 可互换巡航度假公式 ② 仅品牌符号/泛五金无工艺识别点 ③ 氛围/姿态句显著稀释设计事实 ④ 换材质词即可套用他 look |
| 0.5~0.75 | 明显命中 **2 项** |
| 0.75~1.0 | 命中 **3 项及以上**，或全面公式化 |

**典型公式示例**：短夹克 + 条纹衬衫 + 修身短裤/长裤 + 腰带 + 平底鞋

---

## 优化触发

- 任一项惩罚分 **≥ 0.25** → 改写时会收到对应优化提示
- 自适应模式下，任一项 **≥ 0.05** → 即触发优化流程

---

## 得分计算公式

```
P̄ = (非生成导向 + 一致性 + 协调性 + 合理性 + 公式模板) / 5
```

- 通过条件：**P̄ ≤ 0.5**
- 当前 **不参与** 综合分 S_fp 扣减，仅作惩罚门限判定
