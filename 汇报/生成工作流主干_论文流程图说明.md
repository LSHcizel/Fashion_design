# 生成工作流主干 · 论文流程图说明

供后续 **GPT Images 2** 绘制论文用 flowchart。  
只描述**在线生成过程**，不涉及训练。  
视觉语言对齐 PromptEnhancer Fig.2：分区圆角容器、蓝实线主路径、虚线框中间产物。

---

## 0. 一句话主干

> **主题 → 多智能体写 look 描述 → DesignTextEvaluator 双门限评判 →（未过门限则）改写；改写后双门限均提升才用改写稿，否则保留原 description → T2I 生图 → Vision Reflect。**

---

## 1. 生成主干（去枝叶）

| # | 阶段 | 代码锚点 | 输入 → 输出 |
|---|------|----------|-------------|
| 1 | 主题解析 | `ThemeAnalysisAgent` | Theme + Design Target → 子主题 |
| 2 | 章节概念 | `ConceptBrainstormingAgent` | 子主题 → chapter concept |
| 3 | 设计元素 | `DesignElementsAgent` | concept → elements |
| 4 | Look 描述 | `LookDescriptionAgent` | elements → `look_XX.txt` |
| 5 | 文本评判 | `DesignTextEvaluator` | 描述 → `S_fp`, `P̄`，双门限 pass/fail |
| 6 | 改写（条件触发） | Rewriter | 未过门限 → 改写稿；双门限均提升则采用，否则**保留原 description** |
| 7 | T2I | `gpt-image-2` 等 | 定稿描述 → png |
| 8 | 图后反思 | `SingleLookReflectAgent` 等 | 图 → 淘汰 / 重生 |

编排入口：`FashionWorkflow.perform_research` → `process_chapters_sequentially` → `_evaluate_and_optimize_look`。

### 门控与改写（简化口径，画进图）

1. **双门限检查**：`S_fp ≥ τ_s` 且 `P̄ ≤ τ_p` → 通过，保留原 description  
2. **未通过** → 进入改写  
3. **改写后再评**：双门限相对原文**均有提升**（`S_fp↑` 且 `P̄↓`）→ 采用改写稿  
4. **否则** → 仍使用原 description  

> 图中改写块保持简单：一个 `Prompt Rewriter` + 一次再评判 + 二分支（adopt / keep original）。不必展开 K 路扇出、训练回路。

### 勿画进主图

- 一切训练 / SFT / GRPO / RM / 采数旁路  
- 对照实验脚本、汇报 pptx、子主题补位等工程细节  

### 模块图标（生成图用）

| 组件 | 建议 | 说明 |
|------|------|------|
| Fashion Agents | 普通蓝盒 | Prompt agents，无火焰 |
| DesignTextEvaluator | ❄️ | 冻结 LLM-as-judge |
| Prompt Rewriter | 普通蓝盒（或轻标 inference） | 本图不强调训练 |
| T2I (`gpt-image-2`) | ❄️ | API 黑盒 |
| Vision Reflect | ❄️ | 外模型推理 |

```
└───────────────────────────────────────────────────────────────┘
```

## 3. 主图各块文案（英文，便于出图）

### Panel A — Stage 1: Multi-Agent Look Generation

- 输入：`Theme + Design Target`  
- Agent 链：`Theme Analysis` → `Concept Brainstorm` → `Design Elements` → `Look Description`  
- 输出虚线框：`look_XX.txt`（短时尚描述示例即可）

### Panel B — The DesignTextEvaluator

- 输入：`look description`  
- 云朵：`Keypoint-grounded judging`  
- 模块：`DesignTextEvaluator`（❄️）  
- 简表：Coverage / Quality / Penalty → ✓ / ✗ 或分数  
- 汇聚：`S_fp + P̄ → Dual Gate`

### Panel C — Stage 2: Conditional Rewrite → T2I → Vision

- `gate-failed description` → `Prompt Rewriter` → `rewritten description`  
- 再入 `DesignTextEvaluator`（❄️）  
- 二分支框：  
  - `both gates improved` → `use rewrite`  
  - `else` → `keep original description`  
- 汇合为 `final description`  
- → ❄️ `gpt-image-2` → images → ❄️ `Vision Reflect`
