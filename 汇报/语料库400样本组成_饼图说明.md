## 0. 一句话口径

> **Source Corpus = 逆解析 200 + 生成型 200。**  
> 逆解析按 **Chanel / 其他品牌** 二分；生成型按 **100 + 50 + 50**（其中前两档合计 150 条来自生成工作流，后 50 条在生成流基础上引入缺陷），并相对均匀覆盖一众热门品牌。

- 训练 / GRPO / 改写 K 路细节

## 3. 视觉规范

| 元素 | 规范 |
|------|------|
| 画幅 | 横向；三饼并排或「大饼 + 两小饼」 |
| 背景 | 白底；无 3D 爆炸饼、无阴影堆叠 |
| 总库色 | 逆解析 `#5B8DB8`；生成型 `#C47A5A` |
| 逆解析色 | Chanel `#1F4E79`；其他品牌 `#9DC3E6` |
| 生成型色 | 100 `#C47A5A`；50（符号/经典）`#E0A070`；50（缺陷）`#A87878` |
| 标签 | 扇区名 + `n` + `%`；英文主标签，中文可作副标 |
| 字体 | 无衬线；中心数字加粗 |
| 禁止 | 超过 5 个扇区的碎饼；训练回路；文件名 |

### 可选环注（donut）

- Fig-Pie-Inv：中心 `Inverse 200`  
- Fig-Pie-Gen：中心 `Generated 200`，外圈可用淡灰弧标注 `workflow 150` 包住前两扇
