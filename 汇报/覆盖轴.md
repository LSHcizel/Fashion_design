# 覆盖轴

**轴权重**：0.2  
**计分**：每项命中得 1 分、未命中得 0 分，只对「适用」的指标取平均  
**问题**：有没有

**得分评定**
- **1 分（命中）**：文本明确覆盖该指标要求
- **0 分（未命中）**：指标适用但未覆盖，或覆盖不足
- **不适用**：跳过，不计入模块平均

---

## 服装主体

| 指标 | 触发条件 | 命中标准 |
|------|----------|----------|
| 服装品类 | 始终 | 明确给出主体品类（如外套、连衣裙、裤装等） |
| 廓形 | 廓形显著 | 给出整体轮廓或结构趋势 |
| 长度/下摆 | 长度显著 | 给出长度或下摆信息 |
| 肩部结构 | 肩线显著 | 点明肩部结构语言（垫肩、落肩、宽肩、单肩、露肩等），不能仅写「上装」或笼统廓形 |
| 裸露/包裹 | 裸露显著 | 描述显著裸露或包裹区域 |

## 材质颜色

| 指标 | 触发条件 | 命中标准 |
|------|----------|----------|
| 材质类别 | 材质可推断 | 给出主体材质类别 |
| 表面性质 | 表面特征显著 | 给出光泽、哑光、垂坠或硬挺等表面性质 |
| 主色 | 始终 | 给出主色 |
| 副色 | 副色显著 | 描述明显副色；大衣内里、开衩内衬等高对比色块须说明可见条件或与主色区衔接 |
| 配色逻辑 | 多色/强对比 | 交代配色逻辑（单色、同色系层次、补色对比、主次色块等）；仅罗列颜色词不算命中 |
| 图案 | 有图案 | 给出图案类型 |

## 结构细节

| 指标 | 触发条件 | 命中标准 |
|------|----------|----------|
| 开合方式 | 开合显著 | 提到显著开合方式 |
| 功能细节 | 功能细节显著 | 提到显著口袋、挂带或功能细节 |
| 结构工艺 | 工艺显著 | 同时给出工艺类型与大致落位（如胸腰、裙身、袖部）；仅泛称「有细节」或只写「解构」不算命中 |
| 解构 | 有解构 | 提到解构设计 |
| 五金装饰 | 装饰显著 | 提到显著五金或装饰 |

## 造型配件

| 指标 | 触发条件 | 命中标准 |
|------|----------|----------|
| 包袋 | 全套造型且有包 | 包袋视觉突出时，须覆盖以下 **至少 2 项**（理想 3 项齐全）：① 品类/持拿方式 ② 轮廓/体量 ③ 颜色与材质；仅「有个包」不算命中 |
| 鞋履 | 全套造型且有鞋 | 鞋履视觉突出时，须覆盖以下 **至少 2 项**（理想 3 项齐全）：① 鞋型族 ② 跟高/靴筒/鞋头等功能形态 ③ 颜色与材质/饰面；仅「黑鞋/一双鞋」通常不算命中 |
| 首饰 | 首饰显著 | 提到显著首饰或身体装饰 |
| 腰带/腰胯附件 | 腰带/束系显著 | 存在可见腰带、腰封、腰下吊带、腿带绑具等时须提到，并说明与外衣/裤装的附着关系；**剪裁收腰、荷叶摆、省道等不算腰带** |
| 叠搭层次 | 有多层 | 给出层次关系；外套、内搭、腰带、腿带与裤装之间的遮盖与固定顺序可还原 |

## 造型关系

| 指标 | 触发条件 | 命中标准 |
|------|----------|----------|
| 上下比例 | 比例显著 | 提到明显上下比例；长外套、阔腿、厚底鞋与腿带等叠加时须交代主干剪影主次 |
| 不对称 | 有不对称 | 提到不对称设计 |
| 跨单品区分 | 多单品 | 多单品时能区分属性属于哪件单品 |
