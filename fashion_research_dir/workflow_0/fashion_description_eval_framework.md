# Fashion Description Evaluation Framework
## 对标 AlignEvaluator 的时尚设计文本描述评估体系
### 基于 Givenchy Spring/Summer 2019「I Am Your Mirror」

> **评估目标**：给定一段对某套 Look 的文字描述，逐关键点判断该描述是否准确、完整地覆盖了这套服装的核心设计信息。  
> **评定操作**：每个关键点 **Match(1) / Not(0)**，所有适用关键点平均后输出最终分数。  
> **适用范围**：仅针对文本描述，不涉及图像评估。

## 评分聚合公式

```
Step 1：识别该 Look 的描述中涉及哪些关键点（不相关的跳过）
Step 2：对每个适用关键点判断 Match(1) 或 Not(0)
Step 3：按类别聚合 → 类别得分 = 类内适用关键点的平均分
Step 4：所有类别得分平均 → 最终描述质量分数 ∈ [0, 1]
```
